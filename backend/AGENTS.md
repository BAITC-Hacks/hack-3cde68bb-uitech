# Backend

- Java 17, Spring Boot 3.5.16, Maven, Apache POI 5.5.1.
- Сборка из `backend`: `mvn clean verify`. Запуск: `java -jar target/replenishment-0.1.0.jar`.
- Контракт: `../docs/api-contract.md`. Контрольные входы: `../fixtures/contract/`.
- Денежные и количественные величины — BigDecimal. Даты — LocalDate с исключённой правой границей интервала.
- Расчётное ядро не обращается к сети. Не превращать неизвестные остатки и наличие в нули.
- Импорт сохраняет ссылки на исходные ячейки и сообщения о качестве. Не считать помесячные остатки дневной историей stockout.
- Реальные данные и локальное хранилище не добавлять в Git. Параметр `UITECH_DATA_DIR` задаёт каталог данных.
