# Backend

- Java 17, Spring Boot 3.5.16, Maven, Apache POI 5.5.1, PostgreSQL 17, Flyway 11.7.2.
- Сборка из `backend`: `mvn clean verify`. Запуск из корня: `./tools/start_backend.ps1`. По умолчанию профиль postgres; file — явный режим без БД.
- Полный Docker-запуск из корня: `./tools/start_docker.ps1`. Dockerfile собирает исходники с тестами; backend слушает 0.0.0.0 внутри контейнера, исходные файлы — в постоянном томе /data/files.
- Миграции: `src/main/resources/db/migration`. Применённые миграции не менять; добавлять следующую версию. Полный набор не хранить одним JSONB: отдельные таблицы и строки, JSONB сохраняет подробности и источники каждой записи.
- PostgreSQL-тесты включаются через UITECH_TEST_DB_URL, UITECH_DB_USER, UITECH_DB_PASSWORD; создают и удаляют только свою временную схему. Обычные API-тесты используют профиль file.
- Изменение расчёта выполняется под блокировкой строки БД с проверкой expected_revision; сохранять аудит. Исходные XLSX — через FileStorage, ссылки и контрольные суммы — в БД.
- Контракт: `../docs/api-contract.md`. Контрольные входы: `../fixtures/contract/`.
- Исправления исходных фактов создают новый dataset с typed CorrectionAudit в sources. Исторические таблицы читаются через COALESCE(datasets.history_dataset_id,dataset_id); исходная история не дублируется. Менять историю через путь исправления товара нельзя.
- Денежные и количественные величины — BigDecimal. Даты — LocalDate с исключённой правой границей интервала.
- Расчётное ядро не обращается к сети. Не превращать неизвестные остатки и наличие в нули.
- Импорт сохраняет ссылки на исходные ячейки и сообщения о качестве. Не считать помесячные остатки дневной историей stockout.
- Реальные данные, пароли и локальное хранилище не добавлять в Git. UITECH_DATA_DIR — старые JSON для миграции/профиля file; UITECH_FILES_DIR — файлы. UITECH_MIGRATE_LOCAL=true запускает перенос без удаления старых JSON и без перезаписи существующих записей БД.
